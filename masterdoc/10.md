# Exercise 2: Ingest data into the lakehouse

### Estimated Duration: 90 Minutes

## Overview

In this exercise, you will ingest sample data specifically, the Public Holidays table into the lakehouse. You'll configure a data pipeline within Microsoft Fabric to enable efficient data ingestion. The data will be validated and organized into a structured format, ensuring it is ready for further analysis and reporting. This exercise demonstrates the platform's ability to handle complex data processes efficiently, preparing data for advanced analytics and insights.

## Lab objective

- Task 1: Ingest data

## Task 1: Ingest data

In this task, you will import sample data, specifically the Public Holidays table, into the lakehouse by setting up a data pipeline.

1. Navigate to the **Fabric Lakehouse Tutorial** **<inject key="DeploymentID" enableCopy="false" />** Workspace, click on the **+ New item** button and search for the **Pipeline (2)** in the search bar and select **Pipeline (3)** from the Get data blade.

   ![](../media/image0001.png)

2. In the **New pipeline** dialog box, specify the name as **IngestDataFromSourceToLakehouse (1)** and click on **Create (2)**.

   ![new-data-pipeline](../media/10/dp(2).png)

3. In the **Use Copy job?** pop-up, select **No, use copy assistant**.

   ![new-data-pipeline](../media/10/copyassistant.png)

4. From the **Choose data source** pane, select **Sample data (1)**, then click on the **Public Holidays (2)**.

   ![add-pipeline-copy-data](../media/10/sampled(1).png)

5. In the **Connect to data source** pane, preview the **Public Holidays** dataset, and select **Next** to proceed. 

   ![](../media/10/sampled(2).png)

6. In the **Choose data destination** pane, search for **Lakehouse (1)** and select **wwilakehouse (2)**.

   ![add-pipeline-copy-data](../media/10/dp(7).png)

7. In the **Connect to data destination** pane, select **Files (1)** from the Root folder, and then click **Next (2)** to continue.

   ![](../media/10/sampled(3).png)

8. In **Connect to data destination** pane, leave everything default and click on **Next** to proceed.

    ![](../media/10/sampled(4).png)

9. In the **Review + save** pane, the copy summary should be set as **Public Holidays to Parquet**. Click **Save + Run**. You can schedule pipelines to refresh data periodically. In this tutorial, we only run the pipeline once.

   ![](../media/10/sampled(5).png)

10. You can monitor the pipeline execution and activity in the **Output** tab.

      ![](../media/10/sampled(6).png)

11. Now, navigate back to **Fabric Lakehouse Tutorial** **<inject key="DeploymentID" enableCopy="false" />** Workspace and select **wwilakehouse** to launch **Lakehouse explorer**.

    ![add-pipeline-copy-data](../media/10/dp(11).png)

12. Confirm that a new file has been created in the Lakehouse Explorer view, and that it contains the copied data.

    ![](../media/10/sampled(7).png)

      >**Note:** Click Refresh from the toolbar in the Home tab.
